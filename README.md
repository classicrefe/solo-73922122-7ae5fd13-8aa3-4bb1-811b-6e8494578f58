# VCF 队列合并服务（FastAPI + SQLite + pysam）

把分批检测得到的 2~3 份二倍体 VCF 合并成一份队列 VCF，供关联分析使用。
网页完成上传、校验、重复样本取用源选择、后台生成与结果下载，全程在
SQLite 中记录状态，并通过“选择版本号”保证下载到的永远是**当前选择对应
的完整结果**。队列结果生成后，还可在网页上按基因区间分析样本携带的
低频变异（0<AC/AN≤0.25 的 SNV 等位基因）。

## 一、业务规则实现对照

| 需求 | 实现方式 |
| --- | --- |
| 仅接受 2~3 份 VCF（.vcf / .vcf.gz） | `POST /api/batches` 数量与扩展名校验 |
| 同参考版本、坐标排序、每份同坐标仅一条记录 | `app/validation.py` 单文件校验 + `app/cross_check.py` 跨文件检查 |
| 等位基因限 ACGT 序列 | REF/ALT 正则 `^[ACGT]+$`（ALT 为 `.` 的无 ALT 位点合法） |
|  FORMAT 限 GT、AD、PL，且 GT 必需 | 逐记录检查 FORMAT 字段集合 |
| 二倍体 | 每个样本 GT 必须是两个等位槽位（允许 `./.` 缺失） |
| 重复样本必须选择唯一取用原件，未选定不能生成 | `dup_groups` 表 + 生成前置校验 `assert_generation_allowed` |
| 整份检测不能逐位点拼接 | 每个样本在整份输出中只来自一个被选原件（`SampleSource`），缺失位点保持缺失 |
| 联合各位点 ALT，同步重排 GT/AD/PL | `app/merge.py`：ALT 按首次出现取并集，GT 索引、AD（按等位）、PL（三角布局）整体重映射 |
| 新增等位的未知值保留缺失 | 其他文件引入的等位对应 AD/PL 槽位输出 `.`，不伪造数值 |
| 缺少位点不能当作 0/0 | 源文件无该坐标时输出 `./.` 且 AD/PL 全缺失 |
| 同坐标 REF 冲突则整份失败 | 跨文件 REF 比对，冲突写入批次级错误并阻断生成 |
| 后台生成时可改取用源，改动立即使旧结果及在途生成失效 | 每次变更 `selection_version+1`，既有 generation 立即置 `superseded`，worker 在位点间检查版本并中止 |
| 改回也不能恢复 | 版本号只增不减；旧 generation 不会回退，输出文件被删除，需重新生成 |
| 只下载当前选择对应的完整 VCF | 下载接口校验最新 generation 为 done、版本号等于当前版本、文件存在 |
| 失败或重启不开放半成品 | 合并先写 `.partial`，成功才原子 `os.replace`；异常/中止即删除；启动时把在途任务标记失败 |
| 网页显示样本来源和失败原因 | 单页应用展示每份文件的样本、位点、状态、失败原因及批次级错误 |
| 选择当前已完成的队列 VCF 做区间分析 | 分析对象固定为当前批次的最新已完成 generation（与下载接口同源），页面明确显示其 ID 与选择版本 |
| 至多 10 条“基因名+染色体+1 基闭区间” | `app/analysis.py: parse_intervals` 服务端校验（条数、正整数、起点≤终点），前端同步预检 |
| 仅处理 REF 及所有 ALT 均为单碱基的 SNV | 不满足的记录整条跳过并计入“跳过非 SNV” |
| 逐 ALT 按非缺失二倍体 GT 计算 AC/AN | 只有完全判读的二倍体 GT 计入 AN（每样本 2 个等位）与 AC；缺失（含半缺失）GT 一律排除 |
| 取 0<AC/AN≤0.25 的等位基因 | `LOW_FREQ_MAX_AF=0.25`，AC≥1 且 AC/AN≤0.25 才入选 |
| 同一基因区间重叠时位点只算一次 | 同基因同染色体的区间先合并为不相交区间再扫描；不同基因相互独立 |
| 逐样本列出 ALT 拷贝数与有 GT 的候选位点数 | 候选位点=含至少一个入选 ALT 的 SNV 位点；逐样本累计入选 ALT 拷贝数与有 GT 的候选位点数 |
| 全无可判位点显示无法计算 | 样本在全部候选位点均缺失 GT 时 `computable=false`，页面显示“无法计算”而非 0 |
| 缺 GT 不能当作 0/0 | 缺失 GT 既不进 AC/AN，也不进拷贝数与可判位点数（有专门测试锁定） |
| 分析期间取用源改变/结果被重新生成或失效，旧表不可继续显示为当前结果 | 变更取用源或重新生成时既有分析立即置 `superseded`；分析 worker 扫描中轮询失效条件并中止；读取接口每次实时复核（最新 generation、状态、版本、文件存在性），失效分析的结果表一律不下发 |
| 保留合并与下载 | 合并、下载流程与接口未改动，原有测试全部保持通过 |

## 三、本地运行

需要 Python 3.11（依赖见 `requirements.txt`）：

```bash
python -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python run.py
# 打开 http://localhost:8000
```

运行测试（先安装开发依赖 `pip install -r requirements-dev.txt`）：

```bash

```

重新生成演示文件：

```bash
.venv/bin/python demo/generate_demo.py demo
```

## 五、操作流程

1. 网页选择 2~3 份 VCF，点“上传并校验”。
2. 查看每份文件的状态、样本、位点数与失败原因；批次级错误（参考版本
   不一致、REF 冲突等）在页面顶部红色区域展示。
3. 在“重复样本取用源选择”中为每个出现在多份文件中的样本指定唯一原件；
   只有一个来源的样本自动选定。所有重复样本选定前“开始生成”按钮禁用。
4. 点“开始生成”，页面每 1.5 秒轮询状态（等待中/生成中/已完成/失败/已失效）。
5. 完成后点“下载当前选择对应的完整 VCF”。
6. 任何时候改动取用源：页面提示旧结果与在途任务已失效，旧输出文件立即
   删除；需要重新生成后才能再次下载。
7. 生成完成后，在“低频变异区间分析”中填写至多 10 条区间（基因名、
   染色体、1 基闭区间起终点），点“开始分析”；页面按基因展示合并后区间、
   SNV 位点数、候选位点数、入选等位基因（AC/AN）及逐样本携带情况。
   分析期间或之后一旦取用源变更、队列结果被重新生成或失效，旧分析表
   立即不再作为当前结果展示，只显示失效提示，需重新分析。

## 六、HTTP API 摘要

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/batches` | multipart 上传 2~3 份 VCF，返回批次全量状态 |
| GET | `/api/batches/{id}` | 查询批次、文件、选择分组、最新 generation |
| PUT | `/api/batches/{id}/selection/{group_id}` | 表单字段 `file_id`（空串表示取消选择），变更即 bump 版本并失效旧任务与全部分析 |
| POST | `/api/batches/{id}/generate` | 前置校验通过后启动后台合并线程；启动即失效既有分析 |
| GET | `/api/batches/{id}/download` | 仅当最新任务 done 且版本匹配时返回完整 VCF |
| POST | `/api/batches/{id}/analyses` | JSON `{intervals:[{gene,chrom,start,end}]}`（≤10 条 1 基闭区间），对当前已完成队列 VCF 启动低频区间分析 |
| GET | `/api/batches/{id}/analyses/latest` | 查询最新分析；仅当分析仍代表当前队列结果时才携带 `result` 结果表，否则 `result=null` 并给出 `stale_reason` |
| GET | `/api/health` | 健康检查 |

## 七、合并语义细节

- 输出 header 基于第一份源文件重建（contig、INFO/FORMAT/FILTER 定义），
  样本列替换为去重后的队列样本（按源文件顺序首次出现排序），并追加
  `##source` 记录。
- 同一坐标的 ALT 取并集，顺序按文件顺序、位点内 ALT 顺序的首次出现。
- GT：源等位索引映射到联合索引；保留原相位（`/` 与 `|`）。
- AD：按等位逐槽位移位，联合中由其他文件引入的等位槽位置 `.`。
- PL：按 VCF 二倍体三角顺序 `(00),(01),(11),(02),(12),(22)...`
  （索引 `j*(j+1)/2+i`）重映射，未知基因型位置 `.`。
- 源文件缺少该坐标的样本：`GT=./.`、AD/PL 全缺失，绝不写 `0/0`。
- 输出固定 `FORMAT=GT:AD:PL`，QUAL/FILTER/INFO 留空（仅保留 header 定义）。

## 八、低频变异区间分析语义

- 分析对象：当前批次的最新已完成 generation 输出（与下载接口同源）；
  启动分析时记录其 generation ID 与选择版本号。
- 区间：每条为“基因名 + 染色体 + 1 基闭区间 [start, end]”，至多 10 条；
  染色体名需与 VCF contig 命名完全一致（如 `chr1`）。同一基因在同一
  染色体上的重叠/相邻区间先合并为不相交区间，因此重叠覆盖的位点只
  统计一次；不同基因的区间相互独立，同一位点可分属多个基因分别统计。
- SNV 过滤：仅当 REF 与所有 ALT 均为单碱基时该记录才参与统计，否则
  整条跳过（计入“跳过非 SNV”）。无 ALT 的单调位点计入 SNV 位点数但
  不产生候选。
- AC/AN：逐 ALT 统计。AN = 可判样本数 × 2，AC = 可判样本 GT 中该 ALT
  的出现次数。“可判”指完全判读的二倍体 GT；缺失（`./.`）或半缺失
  （如 `0/.`）一律不计入，绝不当作 0/0。AN=0 的位点不产生候选。
- 入选等位基因：0 < AC/AN ≤ 0.25。含至少一个入选 ALT 的位点称为候选
  位点。
- 逐样本输出：低频 ALT 拷贝数（该样本在所有候选位点上入选 ALT 的
  拷贝总数，逐位点按 0/1/2 累加）与有 GT 的候选位点数。样本在所有
  候选位点均无 GT 时显示“无法计算”（此时拷贝数无意义，不显示 0）。
- 失效语义：分析记录绑定其 generation。取用源变更或重新生成时，既有
  分析（含在途）立即置 `superseded`；分析 worker 每 250 条记录轮询
  失效条件（版本号、generation 状态、是否仍为最新、输出文件存在），
  命中即中止且不发布结果；读取接口每次实时复核，失效分析的 `result`
  一律为 `null`，前端只显示失效提示，旧表不会作为当前结果展示。
- 结果规模保护：每个基因最多落库 500 条入选等位基因明细（超出置
  `alleles_truncated`），计数始终精确。

## 十、关于 .vcf.gz

pysam/htslib 要求 `.vcf.gz` 为 **BGZF**（`bgzip`）格式而非普通 gzip，
否则无法随机访问并报 `seek not implemented`。请使用：

```bash
bgzip -c input.vcf > input.vcf.gz
```

仓库 `tests/bgzf_util.py` 是一个仅依赖标准库 zlib 的 BGZF 写入器，供测试
与演示生成合规 `.vcf.gz`，生产环境仍建议使用 htslib 自带的 `bgzip`。
上传普通 gzip 时，页面会在该文件的失败原因中明确提示需要 BGZF。
